# 🙏 Acknowledgements

This project is intentionally small and relies on standard C facilities rather than a third-party application framework.

## Tools and references

- The C standard library provides the runtime functions used for character conversion, terminal input/output, and string operations.
- GCC, Clang, and MinGW-compatible toolchains make source builds possible across supported development environments.
- GNU Make provides repeatable build and test targets.
- GitHub provides source hosting, issue tracking, pull-request review, and workflow execution.
- GitHub Actions, CodeQL, and compiler static analysis provide automated repository checks.
- Mermaid and SVG are used to explain the source architecture and development processes.
