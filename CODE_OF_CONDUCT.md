# Code of Conduct

This project welcomes contributions from people with varied backgrounds and experience. Everyone participating in project spaces should help make them respectful and constructive.

## Expected behavior

- Be considerate and patient.
- Discuss code and ideas without insulting or targeting people.
- Explain disagreements clearly and accept good-faith corrections.
- Respect privacy and do not publish credentials or personal information.
- Give new contributors space to ask questions and learn.

## Unacceptable behavior

Harassment, discrimination, threats, intimidation, doxxing, repeated unwanted contact, deliberate disruption, sexualized attention without consent, and retaliation for raising concerns are not acceptable.

## Maintainer response

Maintainers may remove harmful content, pause a discussion, or limit participation to keep the project safe and productive. Responses should be proportionate and can range from a warning to temporary or permanent exclusion.

## Reporting

Report conduct concerns privately to the maintainer through the contact method on the `@brajesh31` GitHub profile. Include helpful context but avoid sending sensitive information unnecessarily. For security issues, use [SECURITY.md](SECURITY.md). If a concern involves the maintainer, use GitHub's platform reporting tools.

This policy applies to repository discussions, issues, pull requests, and other spaces where someone is participating on behalf of this project.
