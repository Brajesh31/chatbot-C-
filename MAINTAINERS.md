## Review expectations
Maintainers should ensure changes preserve the small, portable C console scope; compile with strict warnings; include relevant tests; update documentation and diagrams when behavior changes; and avoid adding dependencies without a clear benefit.

Security concerns must follow [SECURITY.md](SECURITY.md), not a public issue. General questions belong in [SUPPORT.md](SUPPORT.md). Governance is described in [GOVERNANCE.md](GOVERNANCE.md).
