# Support

This is a small educational command-line project and does not offer a support service or guaranteed response time.

## Questions and bug reports

Search existing [GitHub issues](https://github.com/Brajesh31/chatbot-C-/issues) first. Include the operating system, compiler/version, exact input, expected output, observed output, and steps to reproduce. Do not attach private data or unrelated executable files.

For build problems, include the command and relevant compiler output. Remove local usernames and paths if they are private. Report suspected vulnerabilities privately as described in [SECURITY.md](SECURITY.md), not in a public issue.

## Scope

The current program is a local C console example. It has no hosted chatbot, network service, API, or data store. See [CONTRIBUTING.md](CONTRIBUTING.md) to propose a fix or improvement.
