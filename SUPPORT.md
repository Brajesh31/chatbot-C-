# 🆘 Support

## Project type

Simple C Chatbot is an educational command-line program. It is not a hosted service and does not offer a support contract, guaranteed response time, or production uptime commitment.

## Where to ask

| Need | Recommended channel |
|---|---|
| Reproducible bug | GitHub issue using the bug report form |
| New feature or behavior proposal | GitHub issue using the feature request form |
| Documentation correction | Documentation issue form |
| Terminal accessibility problem | Accessibility issue form |
| Build or usage question | Existing issues and docs, then a public support question |
| Security vulnerability | Private GitHub Security Advisory, not a public issue |
| Conduct concern | Private maintainer contact described in CODE_OF_CONDUCT.md |

Start with the [documentation index](docs/README.md), [FAQ](docs/faq.md), and [troubleshooting guide](docs/troubleshooting.md).

## Information to include

For build issues, include OS, architecture, compiler/version, build command, and relevant compiler output. For behavior issues, include the exact input, expected response, actual response, whether the process continues, and whether the result is repeatable. Identify the source commit or tag.

Redact usernames, private filesystem paths, credentials, personal information, and unrelated terminal content.

## Before reporting

1. Check whether the problem is already reported.
2. Build from current source instead of relying on the historical Windows executable.
3. Follow the documented reproduction steps.
4. Run make check where possible.
5. Use the correct issue form and provide a minimal reproduction.

## Response expectations

The maintainer reviews reports when practical. There is no guaranteed first-response or resolution time. Reports with clear reproduction steps and environment details are easier to triage. Security reports are handled privately where supported.

## Escalation

If an issue is security-sensitive, use the private reporting route in SECURITY.md. If it concerns conduct, use the procedure in CODE_OF_CONDUCT.md. Do not publish confidential details to force a faster response.

## Product boundaries

The current program has no AI model, database, API, browser UI, user accounts, or remote service. Support requests should distinguish desired future functionality from defects in existing behavior.
