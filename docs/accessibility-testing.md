# ♿ Accessibility Testing

## Manual checklist
- [ ] Can the conversation be followed using text output only?
- [ ] Are prompts and responses understandable without color?
- [ ] Is output written in a stable reading order?
- [ ] Are there no flashing, animated, or rapidly refreshed elements?
- [ ] Does Enter submit one logical line?
- [ ] Is the exit command documented clearly?
- [ ] Is EOF behavior explained for terminal users?
- [ ] Have terminal escape sequences been reviewed for assistive-technology impact?

## Test evidence
Record operating system, terminal emulator, assistive technology/version when used, build compiler, steps, observed behavior, and unresolved issues. Do not mark WCAG conformance as achieved: WCAG is primarily a web-content standard and this repository is a terminal application.
