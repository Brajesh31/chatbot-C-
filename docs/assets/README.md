## Asset policy
All SVGs are hand-authored vector explanations, not screenshots of a running UI. They include title and description metadata. This CLI has no graphical UI, so fabricated desktop/mobile screenshots are intentionally not included. The terminal visual is an illustrative transcript, not a screenshot claim.
