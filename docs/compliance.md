# ⚖️ Compliance and Assurance Scope

## Current claims

The repository is an educational C command-line example. It does not claim certification, audit completion, or compliance with a security, privacy, accessibility, or software quality framework.

## Why no compliance certification is claimed

There is no hosted service, account system, personal-data database, payment flow, formal accessibility testing program, or independent control audit. A small set of defensive coding practices and CI checks is useful but does not constitute certification.

## Engineering evidence available

- Strict C11 compilation with warnings treated as errors.
- C unit tests and POSIX interactive tests.
- Linux and Windows build/test workflows.
- Documentation link and SVG validation.
- CodeQL and GCC static-analysis workflows.
- Published scope, privacy, security, and accessibility limitations.

## Future assessment

A compliance project would need a defined legal entity and scope, applicable requirements, evidence collection, control owners, independent review where required, remediation tracking, and periodic reassessment. Do not add compliance badges without substantiated evidence.
