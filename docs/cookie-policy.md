# 🍪 Cookie Policy Applicability

## Current status

This repository is a native C terminal program. The executable does not run in a browser and does not create, read, or transmit browser cookies. It has no browser local storage, advertising tracker, analytics cookie, or web session cookie.

GitHub may use cookies and similar technologies when a person visits the repository website. Those are governed by GitHub's own privacy and cookie information, not by this C source repository.

## If a web client is added

A future web interface must inventory strictly necessary and optional cookies, purposes, providers, lifetimes, consent requirements, opt-out behavior, privacy notices, and tests. Do not copy a cookie banner into the current CLI project or claim that the application manages consent.
