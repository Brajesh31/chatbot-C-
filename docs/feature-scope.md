# 🎯 Feature Scope

## Implemented
- Terminal input/output.
- Lowercase normalization.
- Greeting and status phrase classification.
- Exact `bye` exit command.
- Fallback response.
- Bounded input and EOF handling.

## Not implemented
- AI/LLM integration.
- Internet or external API calls.
- Database or conversation history.
- Accounts/authentication.
- GUI/web/voice interface.
- Multi-language processing.
- Configurable response files.
- Personalization.

Update this list only when source code and tests for the feature have been committed.
