# 🚀 Getting Started

## 1. Check prerequisites

Install a C11-capable compiler. On Linux, GCC or Clang works. On Windows, use a MinGW-w64 distribution that provides gcc. GNU Make is convenient but not mandatory.

Confirm the compiler is visible:

~~~sh
cc --version
~~~

## 2. Clone the source

~~~sh
git clone https://github.com/Brajesh31/chatbot-C-.git
cd chatbot-C-
~~~

## 3. Build

With Make:

~~~sh
make
~~~

Without Make:

~~~sh
cc -std=c11 -Wall -Wextra -Wpedantic chatbot/chatbot.c -o chatbot
~~~

## 4. Start a conversation

~~~sh
./build/chatbot
~~~

On Windows, run the executable generated by your compiler. Enter hello, how are you, or exact bye to explore the current rule set.

## 5. Run checks before changing code

~~~sh
make check
~~~

This runs the C unit tests, Linux interactive smoke tests, and offline documentation validation. Read [development](development.md), [testing](testing.md), and [contributing](../CONTRIBUTING.md) before submitting changes.
