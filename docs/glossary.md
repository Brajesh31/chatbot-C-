# 📖 Glossary

| Term | Meaning |
|---|---|
| C standard library | Portable facilities provided by the C implementation |
| stdin | Standard input stream |
| stdout | Standard output stream |
| fgets | Reads a bounded string from a stream |
| NUL terminator | Zero byte marking the end of a C string |
| Buffer | Fixed-size memory area holding input |
| EOF | End-of-file indicator |
| Substring | Character sequence within another string |
| Enum | C type containing named integral constants |
| Rule-based chatbot | Program selecting fixed responses through conditions |
