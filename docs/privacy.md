# 🔒 Privacy Notes

## Data processed
The application processes text typed into standard input. It uses the bytes only for the current classification and does not store conversation history.

## Data not collected by the application
The current source contains no code for user accounts, network transmission, telemetry, analytics, persistent chat logs, cookies, browser storage, or mobile permissions.

## User responsibility
Terminal input may still be visible to the terminal host, shell session recorder, screen recorder, or operating-system logging configured outside this program. Do not type credentials or sensitive information into a demonstration terminal.

This document describes the source in this repository; it is not a legal privacy notice for a hosted service. If persistence, telemetry, or external services are added, update design, consent, retention, and deletion documentation before release.
