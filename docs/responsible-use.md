# 🧭 Responsible Use

## Intended use

This program is an educational example for learning introductory C concepts and deterministic phrase matching. It is appropriate for classroom exercises, local experimentation, and small code-reading demonstrations.

## Do not overstate its capabilities

The program is not an AI assistant, expert system, moderation service, medical/legal/financial advisor, customer-support agent, or reliable source of factual answers. It does not understand meaning. It reacts to a small set of substrings and otherwise returns a fallback response.

## User-input considerations

Input is processed locally by the current program and is not stored by the application. However, terminals, shell recorders, screen-sharing software, or host operating-system tools may capture terminal content. Do not enter passwords, API keys, or sensitive personal information into shared demonstrations.

## Contributor responsibilities

- Describe the program as rule-based, not AI-powered.
- Do not claim privacy, security, accessibility, or compatibility certification that has not been independently verified.
- Clearly label roadmap features as planned.
- Keep sample output faithful to the actual source.
- Avoid adding tracking, data collection, or remote calls without explicit design and disclosure.

## Reporting misuse or defects

General defects and documentation errors can be reported using the repository issue forms. Potential vulnerabilities should be reported privately using [SECURITY.md](../SECURITY.md).
