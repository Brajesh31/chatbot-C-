# 🏷️ Versioning Policy

The project should use semantic versioning when it begins publishing regular tagged releases:

- **MAJOR:** incompatible change to a published command-line behavior or distribution contract.
- **MINOR:** backward-compatible user-visible feature addition.
- **PATCH:** backward-compatible bug fix or documentation/build correction.

The repository may still be in an untagged development state. Do not describe a version as released until its tag or release artifact exists. Update CHANGELOG.md and release notes with behavior changes, migration notes, and test evidence.
